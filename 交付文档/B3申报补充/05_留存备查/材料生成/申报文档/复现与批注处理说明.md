# 申报作品情况表和研究报告的重建

从项目根目录运行以下命令。输入为根目录原始的两份 Word 文件、试验附件中的计时汇总表和四项实测曲线。若正式试验已完成而表和曲线尚未导出，先在 `03_试验` 目录运行 `generate_trial_tables.py`。

```powershell
$b3Tools = '交付文档/B3申报补充/05_留存备查/材料生成/申报文档'
powershell.exe -NoProfile -ExecutionPolicy Bypass -File "$b3Tools/edit.ps1" -Project (Get-Location).Path
```

脚本使用 Windows PowerShell 和 .NET 的 Open XML、ZIP 读写功能，在 `01_申报材料` 生成作品情况表、申报研究报告及六张原有插图。研究报告另外嵌入试验目录的曲线。原始两份 Word 文件留在原位置。脚本先检查两份原稿的 SHA-256，因为其修订位置与给定表格和段落结构对应。

`edits.json` 记录两份原稿的正文与表格文字修订，键为从零起始的原稿正文段落序号（含表格）。`results.json` 记录新增的试验说明、图注及数据路径。`edit.ps1` 从汇总表读取三次时间并复核算术平均数，再生成表格和正文中的整批均值。`layout.ps1` 设置 A4 分页、表格宽度和字体。输出副本去除原稿批注、编辑器自定义属性与个人编辑元数据。
