# 本体关系球公开聚合

`network.json` 是本机已发布版本的 `/api/v1/network` 白名单响应：186 个公开本体类型节点、1,941 条类间边，其中本体定义边 1,311 条、实例关系聚合边 630 条。它是类层关系图，不是 1,941 条原始实例关系，也不表示物理设备之间存在连线。

实例侧的唯一三元组、原始关系记录、未解析关系等分别保留在 `counts`；本体定义与实例聚合的计数不能相加作为 RDF 全库三元组总数。球面位置由前端计算，只用于关系布局。

每条边保留方向、谓词、类型和来源发布。节点 IRI 与地图/本体导航一致；详细实例通过运行中的服务器 `/api/v1/network-relations` 分页查询。此文件不含服务器的私有关系索引、原始来源记录或访问凭据；`manifest.json` 记录发布 ID、大小和 SHA256。

重新导出时启动本地服务器，将 `/api/v1/network?release_id=<发布ID>` 响应保存为 UTF-8 JSON。生成完整读模型由 `local_server/network.py` 负责；无需将数千个运行期分页文件提交至 GitHub。CAD 小批次对象与 RDF 另见 [cad-gis](../cad-gis/README.md)。
