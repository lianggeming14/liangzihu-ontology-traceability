# 可迁移的本地本体数据服务

用户已于 2026-11-12 明确授权按讨论方案搭建服务器并编写简单指南。本说明把已同意的方案落实为第一版交付边界，后续直接实施，无需重复询问是否开始。

## 目标与现状

以已发布 b93659aaa1b6075a40296400ff9f74332f062439 为源码基线，提供本机稳定输入、查询、导出、可调整配置、备份和换机恢复。现有 PostgreSQL 25449 与 Fuseki 23049/fish_l1 是迁移来源，原环境保留作回退。旧网页是只读审查器，不是入库服务；旧导入器固定批次、路径与端口；旧平台备份的 current_schema 范围不能代表所有 CSV schema。

第一版默认仅本机访问、一个导入任务并发，支持完整批次快照导入、验证后发布、保留历史。网页提供运行状态、导入任务和本体浏览入口；任意本体/实例在线编辑与按 ID 合并不是本版默认行为。稳定业务身份与来源版本分开，不能凭不同批次主键相同自动 sameAs。未知周长、深度、CRS、现场归属不得编造。

## 运行与持久化

独立 local_server Python 包，不启动或发布旧正式平台 WIP。最小运行单元为 PostgreSQL/PostGIS、Fuseki/TDB2、HTTP/API 与串行导入 worker。代码与运行数据分开；所有监听地址、端口、存储根、数据库连接引用、Fuseki 地址、页大小、上传/查询/磁盘限额、备份位置均配置化。目标必须显式校验并有新部署身份，不取消归属检查，也不复制旧 PID/ownership 冒充迁移。

Windows 原生版须在本机实际运行并做新路径恢复验收。提供固定版本的轻量 Compose、Dockerfile 与 Linux/Windows 操作入口；本机若无 Docker 引擎，不通过偷偷开启虚拟化/重启系统安装来冒充已验证，容器与跨 OS 实测状态须明确记录。用户已批准便携部署，常规项目内隔离环境、可逆建库及启动服务均属于执行范围。

本机磁盘初查剩余约 37.6GiB；备份/恢复采用压缩与有界内存处理，并在每个实际大作业前检查空间。保留原服务及文件，不清理无关项目数据。原数据约 PG 5.72GiB、Fuseki 19.26GiB，不能把完整 RDF 装入 RDFLib 内存作为默认验收方式。

## 输入与发布

POST /api/v1/batches 接收受限长度的 ZIP 或 CSV 数据，通过持久化 job_id 返回 202；任务与文件摘要、映射版本/摘要、模式版本绑定。同一输入与规则重复提交复用任务。原始文件私有保留，检查 ZIP 路径、编码、列名、行号、主键、类型与关系目标；未知外键保留未解析状态。

worker 分阶段验证、写 SQL 暂存批次、投影到新的内容寻址 RDF 图、回读验证及 SHACL、生成导航文件，最后发布。SQL 元数据中的唯一 active release 关联 SQL 批次、模型/映射摘要、RDF 图及导航 manifest；每个读请求固定 release_id。失败保留旧生效版本，任务保留阶段与可重试错误；worker 有持久化租约/代次校验，过期任务不能错误激活。历史数据保持可追溯。

复用现有 csv_batch_model、fish_rdf_sample、fish_rdf_validation 的纯建模与验证逻辑；不通过改写旧全局常量来接管原库。新入库使用独立命名空间和角色。bootstrap 可以把完整验证过的现有审查版本注册为初始只读 release，并明确其来源证明。

## 输出与权限

API 提供运行/就绪状态、任务、发布版本、本体子类、按类分页实例、实例属性、双向关系、来源信息、地图图层和导出。统一错误含 code/message/request_id/retryable，响应包含 release_id，游标绑定版本。既有本体浏览页作为兼容入口，保持按层点击与分块加载。

API 不公开任意 SQL/SPARQL 管理接口，不允许通过任意来源 IRI 读取 raw payload。仅业务实例、公开属性和明确 provenance DTO 可读；完整数据备份/导出需要管理凭据。写入用本机 Bearer token，凭据不写入网页源码或 Git；校验 Host/Origin，默认不开放 CORS。区分迁移管理员、导入账号和只读数据账号。只读 API 所需的受限任务登记权限需单独授予。

数据导出覆盖规范实例/关系 JSON、CSV、RDF 数据集；地图输出保留源坐标类型，未配准图层不能谎称 WGS84 GeoJSON。日志脱敏并轮转，健康检查不重复扫描两千多万三元组。

## 备份与换机

备份清单必须枚举每个所需 SQL 数据库及全部非系统 schema（含 fish_review_10pct_v1、csv_batch_a4d78be79a83），角色/扩展/版本、整个 RDF dataset 的默认图和所有命名图、原始 ZIP/必要资料、导航与 OWL/SHACL、控制元数据及任务。凭据和授权密钥单独私有保存。停止本服务写入并核验来源写入边界后捕获一致备份；不更改源数据或终止不属于本部署的进程。

SQL 使用可移植逻辑归档，RDF 使用完整数据集导出并保留 datatype、词法值、命名图及空白节点关系；压缩文件与清单带大小和 SHA256。校验采用流式/磁盘分块策略。恢复必须显式给出新 SQL 与新 RDF 目标，拒绝指回原目标、非空目标及清单不符；在新环境创建归属并核对完整行/字段/关系与 RDF 后才发布。

GitHub Public main 同步代码、配置模板、契约、测试、构建、中文指南和脱敏验收证据。活动库、原件、备份、密码、token、依赖仍在忽略路径，不进入公开仓库。
