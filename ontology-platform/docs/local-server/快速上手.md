# 本地本体服务器：快速上手

服务地址：**http://127.0.0.1:8792/**

1. **启动**：进入 `ontology-platform`，双击 `infra/local-server/local-server.cmd`。电脑重启后也执行这一步。
2. **查看数据**：打开首页，点击“打开本体浏览器”，依次选择本体分类、类型和实例；点击关系可继续查看关联对象，地图页可查看已有图层。
3. **选择版本**：首页“浏览版本（固定）”可查看历史版本。正在查看的内容会固定在所选版本，新数据发布后可手动切换。
4. **导入数据**：准备 UTF-8 CSV 或包含关联表的 ZIP，表头含唯一 `id`。在“导入完整批次”选择文件，填入本机私有配置中的 `LZO_LOCAL_WRITE_TOKEN`，点击上传，查看任务状态。每次导入形成完整的新版本；旧版本仍可选择查看。
5. **导出数据**：在“查询与导出”中选择版本、类型和 JSON、CSV 或 RDF 格式，等待分页完成后下载。关联很多的对象会需要较长时间。
6. **停止**：在该目录打开 PowerShell，执行下面命令，等待结束后再关机。

```powershell
.\infra\local-server\local-server.cmd stop
```

凭据位于 `.runtime/local-server/private.env`，仅在本机使用。数据保持原有的来源、模拟、待核实标记；未知现场数值仍保留为空。

`127.0.0.1` 表示当前电脑。把服务器迁往另一台机器时，需要新建环境并恢复完整备份；数据目录可以调整，本体 ID 和关系随备份保留。GitHub 提供部署代码与指南；实际数据库通过本地生成的完整备份包单独迁移。远程访问可使用已配置的 SSH 隧道。
