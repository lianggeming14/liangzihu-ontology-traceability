梁子湖农业本体数据库 — v0.3 启动说明
更新：2026-10-14

1. 在 implementation 目录双击“启动系统.cmd”，或执行：
   C:/ProgramData/anaconda3/python.exe -B -X utf8 run_server.py --open-browser
   打开 http://127.0.0.1:8787/，点击连接工作台，选择本机演示管理员。
   保持服务进程运行；在启动终端按 Ctrl+C 停止。
   端口已占用时使用 --port 8790，不要同时启动多个相同端口的实例。
   --no-seed 不加载合成示例，--no-demo-login 禁用本机演示角色登录。

2. 推荐体验顺序：
   本体管理 → 查看“农业基础数据本体（合成示例）”结构 → 编辑显示名称；
   查看类、属性、关系表，并区分稳定标识与可改名称。
   对象与关系 → 登记对象或选“映射试用田块（合成示例）”；
   本体管理 → 对象分类，明确类与生效时间；
   数据接入 → 人工观测，选择对象适用的属性、值、单位和时间；
   数据接入 → 登记来源映射 → 样本预览 → 接收结构化记录；
   查看接入回执，按错误修订映射版本后重试，核对原文及尝试历史。

3. 原件与接口：
   上传文件保存原字节、哈希与载体检查结果，不执行图像识别、图片指标或视频抽帧。
   外部模型通过候选断言回传，输入证据与producer版本须明确。
   原件与断言页面可查看来源；已撤回原件不可下载。
   GET /api/v1/openapi.json 查看完整接口合同。
   写请求须带 Idempotency-Key；预览不落库，无需该头。
   真实来源接入使用管理员配置的受控令牌，勿把data/api-tokens.json上传或公开。

4. 数据保留：
   继续使用 data/agri.db，新增003/004迁移，已有记录不清空。
   演示全为合成数据；重复启动不重复插入，管理员改名后也不会被示例重置。
   旧本体无属性字典时明确标记为历史未校验，需新版本补齐语义。
   旧设备采集、批次和溯源页面在“兼容扩展”；默认不启动采集网关。

5. 详细资料：
   DATA_INTAKE_GUIDE.txt：本体/映射/接收/重试的实际操作与JSON示例。
   DATABASE_CORE_V0.3.txt：五大重点、数据库职责、存储与输出边界。
   README.txt：依赖、权限、备份与接口说明。
   验证结果.txt / IMPLEMENTATION_STATUS.json：实际验收与跳过项。
   SQLite已做本地验证，真实梁子湖平台、PostgreSQL、生产身份和TLS尚未验收。
